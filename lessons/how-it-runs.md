<h2>我的信息处理系统 · My Information System and Research SOP</h2>
<p class="date">2026/11/25 · from my note system · 来源于我的笔记系统</p>
<p class="date">Figures were generated by Claude Code. Names are shown by initials. · 图由 Claude Code 生成，人名只留首字母。</p>
<p>First, every few days I pull viewpoints from researchers, engineers, big companies, and others I admire.<br><span class="zh">首先，我每隔几天会拉取我所敬佩的研究者，工程师，大公司等等的一些观点，</span></p>
<p>I judge the value of each viewpoint myself. I write down my thoughts on it, or I group viewpoints into clusters. Then I count which small directions and ideas are rising lately:<br><span class="zh">我会对观点进行自己的估值判断，我会写下关于观点的反思，或者选择把观点聚类，然后计算最近有哪些细分方向和思路：</span></p>
<p>This is how I cluster them now:<br><span class="zh">目前我的聚类方法如下：</span></p>
<p>First, I imagine a scene: an agent does tasks and housework in the world.<br><span class="zh">首先我会想象一个画面：一个 agent 在世界里完成任务、做家务。</span></p>
<p>The agent can be a person or a robot. The world can be real, virtual, or the human body.<br><span class="zh">agent 可以是人，也可以是机器人；世界可以是真的、虚拟的，也可以是人体。</span></p>
<p>The world and the agent are nodes for each other. Agent → world means changing the world, or finding where the world is off. World → agent is, at its core, reinforcement learning.<br><span class="zh">世界和 agent 互为节点：agent → 世界，是去改变世界，或者找出世界哪里有偏差；世界 → agent，本质上是强化学习。</span></p>
<p>When the flow goes both ways, it forms a loop: learning from mistakes and updating all the time.<br><span class="zh">两边来回流成回路，就是在错误中学习、持续更新。</span></p>
<p>Each part of the scene is a node, such as the eyes, the hands, the brain, the legs, and the outside world.<br><span class="zh">画面里每个要素是一个节点，比如眼睛、手、大脑、腿、外部世界。</span></p>
<p>Each node has three stages: input → update → output.<br><span class="zh">每个节点都分三段：输入 → 更新 → 输出。</span></p>
<p>When the flow between two nodes is blocked or slow, the updates on both ends go wrong. That is a problem.<br><span class="zh">两个节点之间的流动不畅、不高效，导致两端的更新出问题，这就是题。</span></p>
<p>For example, in vision → brain, when the viewpoint changes, the flow into the brain breaks.<br><span class="zh">比如视觉 → 大脑，视角一变，进大脑的那条流就断了。</span></p>
<p>Edges have a direction. Vision → hand (after seeing the hand, how should it move, and should it get feedback?) and hand → vision (should the hand send force and contact back, and how?) are two different problems.<br><span class="zh">边有方向：视觉 → 手（看到手之后该怎么动，要不要反馈）和手 → 视觉（手要不要、怎么把力和接触传回来）是两道题。</span></p>
<p>A self-loop is also a problem: the node takes no outside flow and only updates itself. I call this an inner update.<br><span class="zh">自环也是题：节点不接外面的流，只自己更新，这叫内更新。</span></p>
<p>You can zoom out to a bigger scene, but you need to control variables. For example, look at only a few nodes: one cell on the heat map.<br><span class="zh">画面可以放大，但你需要控制变量方法，比如只看其中某几个节点，也就是热力图上的一格。</span></p>
<p>For example, take the same robot doing housework. One study looks at vision and hands; another looks at vision and the brain. The focus is in a different place.<br><span class="zh">比如同样是机器人做家务，一个看视觉和手，一个看视觉和大脑，注意力放的地方不一样。</span></p>
<p>The two are close on the heat map, but they are two different cells.<br><span class="zh">这两个在热力图上离得很近，但是两个不同的格子</span></p>
